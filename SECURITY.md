# Reporting a security issue

Email **security@wecrew.in** with what you found, how to reproduce it, and how you would like to be
credited. You will get a human reply within two working days and a fix or a plan within seven.
Please do not open a public issue for a vulnerability, and do not test against other tenants on
jobwatch.wecrew.in — self-host a copy (`docs/DEPLOYMENT.md`) or use your own organisation.

What is in scope and how the platform is designed to hold up: `docs/SECURITY.md` (controls) and
`docs/SECURITY_OVERVIEW.md` (the version for a security questionnaire). Supported: the latest release
tag on `main`.
